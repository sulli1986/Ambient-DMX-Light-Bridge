# Main Machine Setup (Windows)

Copy/paste these commands in PowerShell or Command Prompt from the project folder.

## 1. Install dependencies

```bat
pip install flask python-osc pillow numpy mss sounddevice mido
```

Do **not** install pygame or python-rtmidi. MIDI uses Windows built-in WinMM.

Full requirements file (same packages):

```bat
pip install -r requirements.txt
```

## 2. Config (first time only)

```bat
copy config.example.json config.json
```

Edit `config.json` for your Lightkey IP, fixtures, etc. if needed.

## 3. Run

```bat
python app.py
```

This starts the bridge **and** the compact always-on-top Lights strip
(no full browser opens automatically). Drag the strip beside ProPresenter.

Full setup UI when needed: http://localhost:5000

To open only the companion later: `python companion.py` (bridge must already be running).

## 4. MIDI setup

MIDI starts automatically when you run `python app.py`.
You do **not** need to install pygame or python-rtmidi.

First time only:
1. Plug in your MIDI controller
2. Open http://localhost:5000 → **MIDI** tab
3. Select the device if it is not already connected
4. Click **Learn** next to each action, then press a pad or move a knob

After that, mappings and the device name stay in `config.json`.
On every launch the app reconnects by itself (and keeps retrying if the
controller is plugged in a few seconds late).

Click **Disconnect** only if you want MIDI off for this session.


## Quick checklist

- Python 3.10+ on PATH
- Lightkey running on Mac with OSC enabled
- This app runs on the Windows machine with ProPresenter / screen capture
- Stream Deck webhooks still work at `http://<this-pc-ip>:5000/hook/...`

## If something fails

| Problem | Fix |
|---------|-----|
| `pip` not found | `python -m pip install ...` |
| Wrong Python | `py -3.12 -m pip install ...` then `py -3.12 app.py` |
| No MIDI devices | Unplug/replug controller, click Refresh, check Windows Sound settings |
| Port 5000 in use | Close the other app, or change the port in `app.py` |
